
# Vectra 混合架构重构计划：Flutter Core + WinUI3 Settings

## 技术栈
- **WinUI3 端**: .NET 8 + Windows App SDK 1.6 + C# + XAML
- **Flutter 端**: 保持现有 Flutter 3.x + C++ 架构
- **IPC**: Named Pipe（双向 JSON 通信）
- **商店预览**: 静态截图/图标，不做实时预览

## 四阶段实施

### 阶段 1：基础设施 + IPC
1. 在项目根目录创建 `vectra_settings/` WinUI3 项目
2. 实现 C# Named Pipe 服务端 (`PipeService.cs`)
3. 在 Flutter C++ 层新增 Named Pipe 客户端 (`pipe_client.h/cpp`)
4. 实现 config.json 共享读写（带文件锁防并发）
5. WinUI3 窗口：MicaAlt 背景 + 基础 NavigationView 骨架
6. Flutter 侧修改：托盘菜单"设置"按钮启动 WinUI3 进程而非创建 Flutter view
7. 验证：两个进程通过 Pipe 通信，设置变更实时同步到 Flutter 卡片

### 阶段 2：设置面板迁移（6 个 tab）
按逆序实现（从简单到复杂），每个 tab 独立可验证：
1. **About** — 版本信息、作者、链接（只读，最简单）
2. **Other** — 更新、自启动、日志、备份恢复
3. **AI** — API 配置、侧边栏外观、热键设置
4. **Appearance** — 布局参数、材质选择、颜色、主题（核心 tab，slider 最多）
5. **Placed** — 已放置卡片列表、尺寸切换、插件设置
6. **Library** — 插件浏览、添加到桌面
7. 移除 Flutter 侧 `panel.dart` 和 `panel_app.dart`

### 阶段 3：插件商店迁移
1. 实现商店 UI（catalog grid、detail page、Markdown 渲染）
2. 插件下载/安装/卸载通过 Pipe 触发 Flutter 侧 `PluginInstaller`
3. 移除 Flutter 侧 `market_app.dart`

### 阶段 4：增强与优化
1. `ConnectedAnimation` 页面过渡动画
2. 键盘快捷键（Esc 关闭、Tab 导航、方向键）
3. UI Automation 屏幕阅读器标签
4. 高对比度模式适配
5. 启动性能优化（WinUI3 窗口延迟加载）
6. 内存占用优化

## IPC 消息协议

```json
// C# → Flutter
{"type":"settingsChanged","data":{...AppSettings...}}
{"type":"pluginInstall","pluginId":"clock","path":"C:\\..."}
{"type":"pluginUninstall","pluginId":"clock"}
{"type":"rescanPlugins"}
{"type":"themeChanged","dark":true}

// Flutter → C#
{"type":"stateSync","data":{...AppState...}}
{"type":"pluginList","plugins":[...]}
{"type":"openTab","tab":"ai"}
{"type":"focusCard","cardId":"clock-abc123"}
```

## 关键文件变更

### 新增文件
- `vectra_settings/` — 完整 WinUI3 项目（Models/ViewModels/Views/Services）
- `windows/runner/pipe_client.h` / `pipe_client.cpp` — Pipe 客户端
- `lib/native/pipe_bridge.dart` — Dart 层 Pipe 消息处理

### 修改文件
- `windows/runner/flutter_window.cpp` — 注册 Pipe 客户端，处理 Pipe 消息
- `windows/runner/main.cpp` — 启动时连接 Pipe
- `lib/ui/app_root.dart` — 托盘菜单"设置"改为启动 WinUI3 进程
- `tool/build_release.bat` — 增加 dotnet build 步骤
- `installer/vectra_portable.iss` — 打包 vectra_settings.exe

### 删除文件（阶段完成后）
- `lib/ui/panel.dart` — 被 WinUI3 设置面板替代
- `lib/ui/panel_app.dart` — 被 WinUI3 替代
- `lib/ui/market_app.dart` — 被 WinUI3 商店替代
